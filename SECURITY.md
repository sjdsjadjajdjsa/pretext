# Security policy

pretext handles one secret: the API key you give it. It is sent only to the
endpoint you configure.

## Supported versions

Only the latest release on the default branch is supported.

## Reporting a vulnerability

Open a private advisory on the repository, or an issue if the report is not
sensitive. Include the version (`pretext --version`), the command, and the
observed behaviour. Redact keys.

Expect an acknowledgement within a week. There is no bounty.

## What this project does not cover

Generated pretexts are fictional exercises. Domains, names, and account numbers
come from the model and are not checked against DNS or any registry. Verify a
pretext before sending it to staff, and remember a simulation is only authorized
when your own security team has approved the target group.
